# 🎮 50-days-life (游戏化习惯养成MVP)

这是一个由产品经理采用 **Vibe Coding (AI 辅助编程)** 独立开发的校园/个人成长类Web App。

## 💡 核心洞察与产品解法

**痛点**：传统打卡工具过于“反人性”，繁琐的任务维护带来极大的操作阻力；且单一的“日历打勾”缺乏长期的多巴胺刺激与情绪安抚，极易让人半途而废。

**解法**：将“50天习惯养成”包装成一场RPG游戏副本。
1. **极简降摩擦**：开局一次性设定目标（如早起、运动），后续每日仅需极简的“一键打卡”。
2. **双轴情绪激励**：摒弃枯燥的虚拟徽章，创新引入“抓娃娃机（消耗金币盲盒）”提供即时的视觉多巴胺刺激；辅以“许愿瓶（Little Joys）”收集日常小确幸，用情绪价值对冲打卡失败的挫败感。

## 🚀 核心功能模块

- **玩家初始化**：自定义50天目标与属性，建立初始心理契约。
- **每日任务看板 (My Home)**：全局进度条联动，即时反馈金币掉落。
- **多巴胺引擎 (Claw Machine)**：像素风抓娃娃机，将虚拟打卡转化为真实的物理操控感与奖励抽取。
- **情绪避风港 (Little Joys)**：非KPI导向的许愿瓶，沉淀用户每日的微小幸福。
- **数据复盘 (Daily Log / Archive)**：像素档案馆与多维度进度条，提供长期成就感。

## 🛠️ 技术实现 (Vibe Coding)

本项目由产品经理**不依赖一次性代码生成**，而是采用“需求拆解 → Prompt 指令 → AI 生成 → 运行测试 → 反馈修改”的敏捷闭环独立完成。基于原生HTML/CSS/JS编写，并采用LocalStorage实现纯前端的轻量级数据持久化。
